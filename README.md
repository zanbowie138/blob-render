# Blob Render

A real-time 3D blob renderer built with Three.js and WebGL shaders. Features ray marching, procedural noise, PBR materials, and interactive controls for creating animated organic shapes.

## Features

- Ray marching with custom GLSL shaders
- Procedural noise-based blob animation
- PBR materials with clearcoat and transmission
- Real-time performance monitoring
- Interactive parameter controls
- HDR environment mapping
